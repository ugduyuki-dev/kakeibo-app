貯金10万円 家計管理アプリ

1. index.html をPCブラウザで開くと試用できます。
2. iPhoneでホーム画面アプリとして使うには、このフォルダ内の全ファイルをHTTPS対応の静的Webホスティング（例：GitHub Pages）に配置します。
3. iPhoneのSafariで公開URLを開き、共有メニュー → ホーム画面に追加 を選びます。
4. 支出データはブラウザのlocalStorageに保存されます。別端末とは同期されません。ブラウザデータ消去やサイトのURL変更で消失する場合があります。
5. 設定・バックアップからJSONを定期的に書き出してください。
6. 決済そのものをブロックする機能はありません。税金の追加納付額は予算に含まれません。
